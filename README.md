# seikotuin_LP

整骨院向けのレスポンシブLPです。

## ファイル構成

- `index.html`：LPの文章・セクション・画像URL・院情報
- `styles.css`：デザイン、余白、配色、スマホ対応
- `script.js`：スムーススクロール、FAQ、表示アニメーション

## 主な構成

1. ファーストビュー
2. 3つの安心ポイント
3. よくある身体のお悩み
4. 当院の施術コンセプト
5. 選ばれる3つの理由
6. 施術メニュー
7. 初回限定オファー
8. 初回施術の流れ
9. お客様の声
10. 院長メッセージ
11. FAQ
12. アクセス
13. LINE / WEB / 電話予約CTA

## 最初に差し替える箇所

`index.html` 内の以下を実際の院情報に変更してください。

- `MEDICAL BODY 整骨院` → 正式な院名
- `山田 太郎` → 院長名
- `00-0000-0000` → 電話番号
- `○○県○○市○○1-2-3` → 住所
- `○○駅から徒歩3分` → アクセス
- `2,980円 / 5,500円` → 実際の料金
- LINE / WEB予約リンク
- サンプルのお客様の声
- Unsplashの仮画像 → 実際の院内・施術・スタッフ写真

## GitHub上で文言を変更する方法

1. `index.html` を開く
2. 右上の鉛筆アイコン（Edit this file）を押す
3. 変更したい文章を検索して書き換える
4. `Commit changes` を押す

## GitHub Pagesで公開する場合

GitHubリポジトリの

`Settings` → `Pages` → `Build and deployment` → `Deploy from a branch`

を選択し、

- Branch：`main`
- Folder：`/ (root)`

にして保存すると、公開URLが発行されます。

## 注意

現在の院名、料金、住所、スタッフ名、お客様の声はLPデザイン確認用のサンプルです。実運用前に実際の情報へ差し替えてください。医療・施術に関する表現は、提供サービスや広告媒体のルールに合わせて最終確認してください。
