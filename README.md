# seikotuin_LP

整骨院向けのレスポンシブLPです。既存のLP構成を維持しながら、**文言・画像・料金・院情報・予約リンクを非エンジニアでも変更しやすい構成**にしています。

## LP構成

構成順は固定です。

1. ファーストビュー
2. 3つの安心ポイント
3. よくある身体のお悩み
4. 当院の施術コンセプト
5. 選ばれる3つの理由
6. 施術メニュー
7. 初回限定オファー
8. 初回施術の流れ
9. お客様の声
10. 院長メッセージ
11. FAQ
12. アクセス
13. LINE / WEB / 電話予約CTA

## ファイル構成

- `index.html`：LPの構造。通常は触らなくてOKです
- `styles.css`：デザイン、余白、配色、スマホ対応
- `site-config.js`：**日常的な文言・画像・料金・院情報・リンクの編集場所**
- `script.js`：`site-config.js` の内容をLPへ反映する処理、FAQ、スムーススクロール、表示アニメーション

---

# 一番簡単な編集方法

基本的には **`site-config.js` だけ編集**してください。

GitHub上で編集する場合：

1. `site-config.js` を開く
2. 右上の鉛筆アイコン `Edit this file` をクリック
3. 変更したい項目を書き換える
4. `Commit changes` をクリック
5. 公開環境へ反映

HTMLやCSSの知識がなくても、`'...'` の中身を変更するだけで主要情報を差し替えできます。

# よく変更する場所

## 院名・電話番号・住所・営業時間

`site-config.js` の `clinic` を編集します。

```js
clinic: {
  brand: 'MEDICAL BODY',
  name: 'MEDICAL BODY 整骨院',
  director: '山田 太郎',
  phoneDisplay: '00-0000-0000',
  phoneHref: 'tel:0000000000',
  address: '〒000-0000 ○○県○○市○○1-2-3',
  access: '○○駅から徒歩3分',
  hours: '平日 9:00〜20:00 / 土曜 9:00〜17:00',
  closed: '日曜・祝日'
}
```

### 電話番号の注意

表示用：

```js
phoneDisplay: '092-000-0000'
```

電話発信用：

```js
phoneHref: 'tel:0920000000'
```

`phoneHref` はハイフンなしにするのがおすすめです。

---

## LINE・WEB予約リンク

`clinic` 内を変更します。

```js
lineUrl: 'https://line.me/R/ti/p/XXXXXXXX',
webBookingUrl: 'https://example.com/reserve'
```

## ファーストビューのコピー

`hero` を編集します。

```js
hero: {
  kicker: '肩・腰・膝のつらさを、我慢する毎日から。',
  titleHtml: 'その痛みの先にある、<br><span>動ける毎日</span>を取り戻す。',
  leadHtml: '丁寧なカウンセリングと姿勢・動作チェックで、<br>今の身体に必要な施術をご提案します。'
}
```

### 色付き文字

`<span>...</span>` で囲った部分がアクセントカラーになります。

### 改行

`<br>` を入れると改行できます。

---

## 初回料金

2か所を編集します。

```js
hero: {

```

```js
firstOffer: {
  regularPrice: '通常 5,500円',
  price: '2,980'

```

# 画像の変更方法

画像URLは `site-config.js` にまとめています。

例：

```js
hero: {
  image: './assets/hero.jpg'
}
```

または外部画像URL：

```js
hero: {
  image: 'https://example.com/images/hero.jpg'
}
```

主な画像項目：

- `hero.image`：ファーストビュー
- `concept.image`：施術コンセプト
- `strengths.items[0].image`：選ばれる理由1
- `strengths.items[1].image`：選ばれる理由2
- `strengths.items[2].image`：選ばれる理由3
- `staff.image`：院長写真

## おすすめの画像サイズ

- ファーストビュー：1200 × 1600px 前後の縦写真
- コンセプト：1200 × 1400px 前後
- 選ばれる理由：1200 × 800px 前後
- 院長：1000 × 1200px 前後

元画像は大きめを用意すると、PC・スマホ両方できれいに表示しやすくなります。

# お客様の声を変更する

`voices.items` を変更します。

```js
{
  age: '50',
  profile: '50代 女性',
  sub: 'デスクワーク',
  title: '説明がわかりやすく安心できました',
  text: 'ここに実際のお客様の声を入力します。'
}
```

公開前に、デモ用のお客様の声は実際の内容へ必ず差し替えてください。

---

# FAQを変更する

`faq` 内の質問と回答を書き換えます。

```js
faq: [
  {
    q: '予約は必要ですか？',
    a: '予約優先制です。WEBから24時間ご予約いただけます。'
  }
]
```

現在のレイアウトは4件表示を前提にしています。

---

# デザインを変更したい場合

`styles.css` を編集します。

日常的なコピー修正・画像差し替えでは、原則として `styles.css` は触らないでください。

デザイン変更をコーダーへ依頼するときは、以下のように伝えるとスムーズです。

- 「構成順は変更しない」
- 「`site-config.js` の編集方式は維持する」
- 「文言や画像はHTMLへ直接固定しない」
- 「PC / タブレット / スマホのレスポンシブを維持する」

# GitHub Pagesで公開する方法

GitHubリポジトリの

`Settings` → `Pages` → `Build and deployment` → `Deploy from a branch`

を選択します。

設定：

- Branch：`main`
- Folder：`/ (root)`

保存すると公開URLが発行されます。

# 公開前チェック

- 院名
- 院長名
- 電話番号
- 住所
- 営業時間 / 定休日
- LINEリンク
- WEB予約リンク
- Google Mapリンク
- 初回料金 / 通常料金
- お客様の声
- 院長写真
- 施術写真
- 医療・施術に関する表現

現在の院名、料金、住所、スタッフ名、お客様の声、画像の一部はデザイン確認用サンプルです。実運用前に実際の情報へ差し替えてください。

施術効果や症状に関する表現は、実際の提供内容・関連法令・広告媒体の審査基準に合わせて最終確認してください。
